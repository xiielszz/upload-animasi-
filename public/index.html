Roblox Tools

Inspect file .rbxm / .rbxmx, dan bulk-upload animasi/audio ke Roblox lewat Open Cloud Assets API. API key & User ID tersimpan di browser masing-masing (bukan server), jadi aman dipakai bersama.

Pengaturan Akun Roblox

Upload Sebagai

Klik untuk pilih file, atau drag & drop di sini
.rbxm · .rbxmx — diproses 100% di browser kamu
Penting: 1 file yang diupload ke Roblox = 1 asset Animation. Kalau kamu punya 1 file gabungan berisi banyak animasi, upload langsung file itu cuma jadi satu asset saja. Ada 3 cara di bawah: Opsi A pecah otomatis dari 1 file .rbxmx gabungan (dideteksi dari tiap KeyframeSequence), Opsi B upload file yang sudah terpisah satu-satu, atau Opsi C upload 1 file .zip berisi banyak file animasi sekaligus. File .rbxm biner tidak bisa di-split otomatis (formatnya proprietary) — save as .rbxmx dulu di Studio kalau butuh itu.

Opsi A — Split Otomatis dari 1 File Gabungan

Upload 1 file .rbxmx yang isinya banyak animasi (KeyframeSequence) digabung — tool ini otomatis memecahnya jadi file terpisah per animasi, lalu masuk ke daftar upload di bawah.

Klik untuk pilih 1 file gabungan, atau drag & drop di sini
.rbxmx (XML) saja — .rbxm biner tidak bisa di-split otomatis

Opsi C — Upload dari File ZIP

Punya folder animasi (masing-masing sudah file .rbxm/.rbxmx terpisah) yang di-compress jadi 1 ZIP? Upload ZIP-nya di sini — tool otomatis membuka isinya di browser dan menambahkan tiap file animasi ke tabel di bawah. Kalau ada file .rbxmx di dalam ZIP yang ternyata masih gabungan beberapa animasi, otomatis dipecah lagi juga.

Klik untuk pilih file ZIP, atau drag & drop di sini
.zip — isinya boleh campur .rbxm dan .rbxmx, boleh di dalam folder/subfolder

Opsi B — Upload File yang Sudah Terpisah

Kalau kamu sudah punya file per-animasi (hasil split manual atau dari Opsi A), pilih semuanya di sini.

Klik untuk pilih beberapa file, atau drag & drop di sini
.rbxm · .rbxmx — masing-masing file dianggap 1 animasi
